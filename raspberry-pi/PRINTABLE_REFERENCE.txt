Connect to Pi:
  ssh pi@victron-monitor.local
  (or use IP address from above)

Check if service is running:
  sudo systemctl status victron-collector.service

View live data:
  sudo journalctl -u victron-collector.service -f
  (Press Ctrl+C to stop viewing)

Restart the service:
  sudo systemctl restart victron-collector.service

Stop the service:
  sudo systemctl stop victron-collector.service

Start the service:
  sudo systemctl start victron-collector.service


┌──────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                          │
└──────────────────────────────────────────────────────────────────────────┘

No data showing in dashboard:
  1. Check service: sudo systemctl status victron-collector.service
  2. View logs: sudo journalctl -u victron-collector.service -n 50
  3. Check USB: ls -l /dev/ttyUSB*
  4. Restart: sudo systemctl restart victron-collector.service

Can't connect via SSH:
  1. Check Pi has power (green LED should be on)
  2. Check network connection (WiFi or Ethernet)
  3. Find IP from router admin page
  4. Try: ping victron-monitor.local

Service won't start:
  1. Test manually: cd ~/victron-solar && python3 victron_collector.py
  2. Check for errors in output
  3. Verify USB cable is connected
  4. Reboot Pi: sudo reboot

Dashboard shows old data:
  1. Check Pi is powered on
  2. Check internet connection: ping google.com
  3. Restart service: sudo systemctl restart victron-collector.service

┌──────────────────────────────────────────────────────────────────────────┐
│ EMERGENCY PROCEDURES                                                     │
└──────────────────────────────────────────────────────────────────────────┘

System completely unresponsive:
  1. Unplug power from Pi
  2. Wait 10 seconds
  3. Plug power back in
  4. Wait 2 minutes for boot
  5. Check if service auto-starts

Lost SSH password:
  1. Power off Pi
  2. Remove SD card
  3. Insert into computer
  4. Create file: boot/ssh (empty file)
  5. Edit boot/userconf.txt with new password hash
  6. Re-insert card and boot Pi

SD card corrupted:
  1. Reflash new SD card with Raspberry Pi OS
  2. Run setup script again
  3. Configuration will be restored from Supabase
